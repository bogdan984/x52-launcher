# Сторонние компоненты

Установщик X52 Launcher включает или использует:

| Компонент | Лицензия | Источник |
|---|---|---|
| ViGEmBus 1.22.0 (драйвер, ставится по выбору) | BSD-3-Clause | https://github.com/nefarius/ViGEmBus |
| vgamepad 0.1.0 | MIT | https://github.com/yannbouteiller/vgamepad |
| pygame 2.6.1 (и SDL2) | LGPL-2.1 (SDL2 — zlib) | https://github.com/pygame/pygame |
| Python 3.13 | PSF License | https://www.python.org |
| PyInstaller (загрузчик) | GPL-2.0 с исключением для собранных программ | https://github.com/pyinstaller/pyinstaller |

pygame поставляется отдельными динамическими библиотеками внутри папки программы, их можно заменить своей сборкой (требование LGPL).

Saitek, Logitech, X52, DCS World, ACE COMBAT — товарные знаки их владельцев. Проект с ними не связан.
