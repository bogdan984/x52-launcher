X52 Launcher 5.5.32 — ВСЕ ПУНКТЫ ЛАУНЧЕРА НА ПРИМЕРЕ СУ-27
Три профиля: «Взлёт Су-27», «Полёт Су-27», «Посадка Су-27»
======================================================================

ПРЕЖДЕ ЧЕМ ЧИТАТЬ
  • Клавиши Су-27 ниже — клавиши DCS по умолчанию (Су-27, FC3). Перед
    назначением проверьте их в DCS: Настройки → Управление → Су-27 →
    поле «Поиск». Если у вас другая клавиша — ставьте в лаунчере вашу.
    Главное правило: клавиша в лаунчере = клавиша в DCS.
  • Номера кнопок X52 у разных драйверов могут отличаться. Нажмите
    кнопку на X52 — на «Карте кнопок» подсветится её плитка. Правый
    щелчок по плитке — дать ей понятное имя («Пинки», «Тумблер T1»…).
  • Ручку, РУД и кнопки DCS видит сам. Лаунчер ДОБАВЛЯЕТ к этому:
    макросы, перебор, долгое/короткое нажатие, обзор мини-стиком,
    плавный зум, смену профиля. Если кнопка X52 назначена И в DCS, И в
    лаунчере — сработают оба. Кнопки, настроенные в лаунчере, в DCS
    оставляйте пустыми.
  • Порядок: ЧАСТЬ 1 — как сделать три профиля и переключать их.
    ЧАСТЬ 2 — каждая вкладка, поле и галочка по порядку, с примером.
    ЧАСТЬ 3 — готовая раскладка всех трёх профилей одной таблицей.


######################################################################
ЧАСТЬ 1. ТРИ ПРОФИЛЯ И КАК ОНИ ПЕРЕКЛЮЧАЮТСЯ
######################################################################

Профиль — это полный набор настроек: что делает каждая кнопка X52,
мини-стик, зум, оси. Идея: одни и те же кнопки на разных этапах полёта
делают разное.
  Взлёт   — запуск, фонарь, тормоза колёс, закрылки, шасси.
  Полёт   — оружие, РЛС/прицел, ловушки, захват цели.
  Посадка — шасси, закрылки, щиток, парашют, тормоза колёс.
Общее для всех трёх (обзор, зум, шасси) настраивается один раз и
копируется блоком «Применить и в профилях».

1.1. Создать профили
  1) «Главная» → «Профиль:» → «Новый…» → шаблон «DCS World — игра сама
     видит X52; автопрофиль по DCS.exe» → название «Взлёт Су-27» →
     «Создать». Шаблон сам вписывает DCS.exe и включает автосмену.
  2) Настройте «Взлёт Су-27» (общие кнопки — обзор, зум, шасси — сразу
     здесь, см. часть 2).
  3) «Новый…» → «Копия текущего профиля» → «Полёт Су-27». Копия берёт
     ВСЕ назначения — меняете только то, что отличается.
  4) Так же «Посадка Су-27».
  Шаблоны в окне «Новый…»:
    • DCS World / War Thunder / IL-2 — игра видит X52 сама, лаунчер
      добавляет клавиши; exe игры уже вписан для автопрофиля.
    • «Другая игра — только свои клавиши» — то же без exe.
    • «ACE COMBAT 8» — действия игры и виртуальный геймпад (для Су-27
      не нужен).
    • «Копия текущего профиля» — для этапов одной игры (наш случай).
  Назначение осей и выбранный джойстик всегда копируются из текущего.

1.2. Переключать профили — три способа (выберите ОДИН основной)
  СПОСОБ А (рекомендую) — колесо режимов X52 (на ручке, 3 положения):
    «Режимы и автопрофиль» → «Профиль по колесу режимов X52» →
    галочка «Поворот колеса включает профиль»:
       положение 1 → «Взлёт Су-27»
       положение 2 → «Полёт Су-27»
       положение 3 → «Посадка Су-27»
    Колесо физически стоит в положении, поэтому всегда видно, какой
    профиль включён, и сбиться нельзя. При запуске лаунчера сразу
    включается профиль текущего положения колеса.
  СПОСОБ Б — кнопкой (если колесо нужно для «слоёв», см. 2.6):
    «Карта кнопок» → плитка свободной кнопки (например «Function» на
    дисплее РУДа) →
    колонка «Срабатывание при нажатии» → «Смена профиля» → «Новый
    профиль: (следующий профиль)» → внизу «Применить и в профилях»: «Все»
    → OK. Короткое нажатие: Взлёт → Полёт → Посадка → Взлёт…
    Колонка «при долгом нажатии» той же кнопки → «Смена профиля» →
    «Взлёт Су-27» — долгое нажатие сразу возвращает к взлёту.
  СПОСОБ В — автоматически при посадке в кабину (см. 2.6, «Автопере-
    ключение»): сели в Су-27 — включился «Взлёт Су-27».
  Не назначайте «Смену профиля» на сами кнопки колеса — сработают
  оба механизма.

1.3. Видеть, какой профиль включён, прямо в игре
  «Режимы и автопрофиль» → «Оверлей в игре» → «Показывать поверх игры»
  → «При смене, секунд: 2». Повернули колесо — в углу экрана на 2 с
  появится «Полёт Су-27». DCS должен быть в оконном режиме или
  «без рамки» (borderless) — в полноэкранном Windows рисовать поверх
  не даёт.


######################################################################
ЧАСТЬ 2. ВСЕ ВКЛАДКИ, ПОЛЯ И ГАЛОЧКИ ПО ПОРЯДКУ
######################################################################

Вкладки лаунчера слева направо:
  Карта кнопок · Главная · Оси и РУД · Отклик ручки · Назначение (как
  в игре) · Режимы и автопрофиль · Обзор (голова / X52) · Установка.
Внизу окна: «Текущий профиль: …» и строка подсказки.
Сверху меню: Файл · Правка · Последовательности · Профиль · Справка.

======================================================================
2.1. ВКЛАДКА «ГЛАВНАЯ»
======================================================================
Блок «Игра (профиль настроек)»
  • «Профиль:» — список профилей; выбрали — профиль включился.
    «Новый…», «Переименовать…», «Удалить» — понятно по названию.
  • «Виртуальный геймпад Xbox 360» — лаунчер создаёт невидимый геймпад.
    Для Су-27 ВКЛЮЧИТЬ во всех трёх профилях: через его ПРАВЫЙ стик
    в DCS идёт обзор мини-стиком и хаткой, через левый X — плавный зум.
    (Ручку и РУД DCS читает с X52 сам — в DCS у колонки «Controller
    (XBOX 360)» должны быть только JOY_RX, JOY_RY и, для зума, JOY_X.)
    Если в одном профиле геймпад выключен — при смене профиля DCS
    напишет «геймпад отключён». Поэтому — галочка во всех трёх.
  • «Действия ACE COMBAT 8» — список действий AC8 на вкладке
    «Назначение». Для Су-27 не нужен.
  • «Кнопка «ИГРАТЬ» запускает:»
      Steam, App ID — для DCS в Steam: 223750;
      Программу — путь к DCS.exe или ярлыку («Обзор…») — если DCS
        не из Steam;
      Ничего (только мост) — если DCS вы запускаете сами.
Блок «Устройство, мост и запуск игры»
  • «Джойстик:» — должен быть Saitek X52. «Обновить» — если подключили
    после запуска.
  • «▶▶ ИГРАТЬ» — включает мост, запускает DCS, сворачивает лаунчер.
  • «▶ Запустить мост» — мост = лаунчер начинает читать X52 и посылать
    клавиши/геймпад. Без моста назначения не работают. Мост включать
    ДО запуска DCS (иначе в DCS — «Опрос устройств»).
  • «Обзор головой через opentrack» — та же галочка, что на вкладке
    «Обзор»; нужна, только если есть трекер головы.
  • «Включать мост при открытии лаунчера» — советую включить.
  • «Сворачивать лаунчер при запуске игры» — включить.
  • «Отдавать приоритет игре» — Windows даёт DCS больше процессора;
    включить, если FPS проседает.
Блок «Физический X52 (в реальном времени)» — проверка: двигайте ручку,
  жмите кнопки — подсвечиваются. Отсюда же видно номера кнопок.
Блок «Что видит игра (виртуальный Xbox 360)» — левый/правый стик,
  LT/RT, «Нажато:». Подвигали мини-стик — шевелится правый стик:
  значит, обзор в DCS пойдёт.

======================================================================
2.2. ВКЛАДКА «КАРТА КНОПОК» — главное место настройки
======================================================================
Слева — устройства. Справа сверху — «Все назначенные действия»
(таблица: что, на какой кнопке, когда срабатывает, клавиша, повтор,
профиль, последовательность). Двойной щелчок по строке — открыть.
Ниже — подвкладки: Кнопки · Хатки · Оси · Мини-стик · Зум.
Над плитками (если включены слои, 2.6) — «Слой:» и «за колесом».

Плитка кнопки: имя, значок (горит, когда кнопка нажата), отметки
SP / LP / RL — что назначено: нажатие / долгое / отпускание.
Правый щелчок по плитке — переименовать. Щелчок по значку — окно
«Выбор срабатывающего действия».

----------------------------------------------------------------------
2.2.1. ОКНО «ВЫБОР СРАБАТЫВАЮЩЕГО ДЕЙСТВИЯ — <кнопка>»
----------------------------------------------------------------------
В заголовке — КАКАЯ кнопка настраивается (та, по которой щёлкнули).
Три колонки — три момента, когда кнопка может сработать:
  • «Срабатывание при нажатии» (SP)
  • «Срабатывание при долгом нажатии» (LP) — держали дольше порога
    «Долгое нажатие» (по умолчанию 500 мс, вкладка «Режимы…»)
  • «Срабатывание при отпускании» (RL)
Галочка вверху колонки включает её. Если включены И «нажатие», И
«долгое» — «нажатие» срабатывает только на КОРОТКОЕ нажатие (отпустили
раньше 500 мс). Так одна кнопка делает два разных дела.
  Пример (Полёт Су-27), кнопка «C» на ручке:
    при нажатии (короткое) — «Захват цели» Enter;
    при долгом нажатии     — «Сброс захвата» Backspace.

В каждой колонке «Название:» (видно в таблице и оверлее) и ОДИН из
пяти типов:

(1) «Нажатие клавиши»
  • «Модификатор:» LCtrl LShift LAlt RCtrl RShift RAlt — галочки.
  • «Клавиша:» — из списка или «…» и нажать клавишу на клавиатуре.
  • Без галочек ниже — ОДНО короткое нажатие клавиши, сколько бы вы ни
    держали кнопку.
      Пример (все профили): Тумблер T1 → G «Шасси».
      Пример (Взлёт): кнопка «A» → модификатор LCtrl + C «Фонарь».
  • «Повтор, мс» — пока держите, клавиша жмётся снова и снова с этим
    интервалом.
      Пример (Полёт): кнопка «B» → Insert «Тепловые ловушки», Повтор
      400 мс — держите кнопку, ловушки сыплются каждые 0,4 с.
  • «непрерывно (держать) > N мс» — клавиша зажата, пока зажата кнопка.
      N = 0 — сразу.
        Пример (Взлёт и Посадка): Пинки → W «Тормоза колёс»,
        непрерывно > 0 — держите пинки, колёса тормозят.
      N > 0 — клавиша нажмётся, ТОЛЬКО если кнопку держать дольше N мс;
        короткое нажатие не делает ничего. Защита от случайного нажатия.
        Пример (Полёт): кнопка «D» → LCtrl + W «Аварийный сброс
        подвесок», непрерывно > 1000 мс — сбросит только после
        секунды удержания, случайное касание безопасно.
      Без галочки поле серое, кнопка — одно короткое нажатие.

(2) «Последовательность нажатий» — макрос: несколько клавиш по времени.
  • «Последовательность:» — выбрать из библиотеки; «Создать /
    изменить…» — открыть редактор (то же, что меню «Последователь-
    ности → Просмотр последовательностей…», см. 2.2.6).
  • Без галочки: нажали кнопку — макрос проходит до конца сам.
      Пример (Взлёт): Тумблер T2 → «Запуск Су-27»:
        шаг 1: LCtrl+C (фонарь закрыть), начало 0 мс, держать 100;
        шаг 2: RShift+Home (запуск двигателей), начало 2000, держать 100.
  • «удержание (шаги идут, пока держите кнопку)» — отпустили кнопку —
    оставшиеся шаги НЕ идут; нажали снова — с первого шага.
      Пример (Полёт): кнопка «E» → «Серия ЛТЦ»: Insert 0 мс, Delete
      300, Insert 600, Delete 900, Insert 1200… с «удержанием» —
      держите кнопку, пока нужна серия; отпустили — серия оборвалась.

(3) «Перебор по кругу (нажатие — следующий шаг)» — одна кнопка
    листает варианты: 1-е нажатие — шаг 1, 2-е — шаг 2, после
    последнего снова первый. Каждое нажатие — одна клавиша.
  • Список шагов, кнопки «+ шаг» (нажать клавишу), «Изменить», «−»,
    «↑» «↓» (порядок).
  • «Держать клавишу, мс:» — сколько держать клавишу шага (100 хватит).
  • «к 1-му шагу: держать > N мс» — галочка: если кнопку держать
    дольше N мс — счёт сбрасывается на шаг 1 (без нажатия клавиш);
    тогда шаг срабатывает при ОТПУСКАНИИ кнопки. Без галочки — шаг
    сразу при нажатии, сброса нет.
  • «с 1-го шага при смене профиля» — галочка: сменили профиль —
    перебор снова с шага 1. Снята — помнит, где остановился.
      Пример (Полёт): хатка на РУДе ↑ → «Режимы прицела»:
        2 (ДВБ) → 3 (вертикальное сканирование) → 4 (оптика/
        боресайт) → 5 (шлем); к 1-му шагу > 1000 мс; с 1-го шага при
        смене профиля — да. Нажимаете — режимы по кругу; подержали
        секунду — снова начнёт с ДВБ.
      Пример (Полёт): кнопка «Fire» → «Смена оружия» — у Су-27 это
        одна клавиша D, перебор не нужен, достаточно (1).

(4) «Смена профиля» — ЭТА кнопка включает профиль.
  • «Новый профиль:» — конкретный профиль, «(следующий профиль)» или
    «(предыдущий профиль)». Срабатывает в выбранной колонке (нажатие /
    долгое / отпускание).
      Пример «временный профиль» (пинки-свитч): в «Полёт Су-27»
      кнопка «i» при нажатии → «Посадка Су-27»; в «Посадка Су-27» та же
      кнопка при отпускании → «Полёт Су-27». Пока держите — работают
      кнопки посадки, отпустили — снова полёт.
  • ВАЖНО: назначения у каждого профиля свои. Если кнопка переключила
    вас в другой профиль, вернуться ею можно, только если она назначена
    и там (сделайте это там или галочками «Применить и в профилях»).
  Если профили переключаете колесом (способ А) — этот тип не нужен.

(5) «Обзор DCS (правый стик геймпада)» — кнопкой/хаткой смотреть
    в кабине. «Команда DCS:»
  • «… горизонталь (абсолют) — влево / вправо», «… вертикаль
    (абсолют) — вверх / вниз» — пока держите, взгляд уходит туда.
      Пример (все профили): хатка на ручке ← → ↑ ↓ — четыре команды,
      колонка «при нажатии».
  • «Центровка обзора (для режима «как мышь»)» — взгляд в центр.
      Пример (все профили): одна свободная кнопка (в MANUAL — кнопка 31):
      при нажатии — Num Enter «обычный масштаб»; при отпускании —
      «Центровка обзора». Одна кнопка сбрасывает и зум, и взгляд.
  Нужно: «Виртуальный геймпад» и в DCS JOY_RX/JOY_RY на «Камера в
  кабине … (абсолют)» без модификатора. Всё про обзор, центровку и
  этот список подробно — файл ОБЗОР_DCS_НАСТРОЙКА.txt.

Если колонка показывает «Это действие настроено особо…» — оно сделано
на вкладке «Назначение» (переключатель, профили по кругу из списка,
свои шаги) и меняется там.

Блок внизу окна «Применить и в профилях (галочка — у этой кнопки там
так же)» — виден, если включено «Выбор профилей» (2.6):
  • Галочки профилей: стоит — в том профиле эта кнопка будет такой же.
    Снятая галочка УБИРАЕТ назначение этой кнопки в том профиле.
  • «Все» / «Ни одного».
    Пример: тумблер T1 «Шасси» → «Все» → OK — шасси одинаково во всех
    трёх профилях. Кнопку «B» (ловушки) — только «Полёт Су-27».

----------------------------------------------------------------------
2.2.2. ПОДВКЛАДКА «ХАТКИ»
----------------------------------------------------------------------
У каждой хатки 8 направлений (N, NE, E, SE, S, SW, W, NW), каждое —
как отдельная кнопка со своим окном и SP/LP/RL. Диагональ срабатывает
только на диагонали. Когда хатка нажата, в названии вкладки видна
стрелка («Хатки ↑»).
  Пример: хатка на ручке — обзор (2.2.1, тип 5); хатка на РУДе —
  перебор режимов прицела (Полёт), в Посадке её ↓ — тормозной парашют P.

----------------------------------------------------------------------
2.2.3. ПОДВКЛАДКА «ОСИ» — крутилки, ползунок, РУД как КНОПКИ
----------------------------------------------------------------------
Каждая ось — шкала с красными отметками порогов и две стрелки «−» и
«+». Ось работает как кнопка: «нажатие» — ось перешла порог,
«отпускание» — вернулась. Кнопка «+ : ≥ 0.80» / «− : ≤ −0.80» —
порог (−0.95…0.95). Щелчок по стрелке — то же окно, что у кнопки.
  Пример (Полёт): крутилка I вправо до упора («+ ≥ 0.80») → I
  «РЛС вкл/выкл»; влево до упора («− ≤ −0.80») → O «ОЛС вкл/выкл».
  (У Су-27 это переключатели: повторный проход порога выключит.)
«⚠ работает как … — будет двойное срабатывание» и кнопка «Откл.
аналог»: ось уже используется лаунчером как ручка/РУД/обзор. Для
крутилок и ползунка в DCS-профиле этого обычно нет.
Плавный зум на ползунок СЮДА не назначать — будет рывком у краёв;
для зума — подвкладка «Зум».

----------------------------------------------------------------------
2.2.4. ПОДВКЛАДКА «МИНИ-СТИК» (обзор мини-стиком на РУДе)
----------------------------------------------------------------------
Слева — превью и «Режим обзора (когда opentrack выключен)»:
  • «Как стик» — смотрите, пока отклонён, отпустили — взгляд в центр.
    (Режим ставьте ОДИН во всех трёх профилях — иначе при смене
    профиля взгляд прыгает; см. ОБЗОР_DCS_НАСТРОЙКА.txt, 4.3.)
  • «Как мышь» — взгляд остаётся там, куда повернули; назад —
    «Центровка обзора». Удобно для осмотра кабины и задней полусферы.
  • «Скорость «мыши»» — 2–3 (меньше — плавнее).
  • «Скорость поворота «как стик»» — 5–6 (0 даёт рывки).
  • «Насколько далеко поворачивается обзор» — 1.0 = полностью.
  • «Центровать обзор сейчас».
Справа:
  • «Включить мини-стик в текущем профиле» — да во всех трёх.
  • «Мини-стик работает в профилях колеса режимов» — отметьте все три
    (если галочки выбора профилей включены).
  • «Чувствительность» 1.0 (меньше 1 — в «как стик» взгляд не
    доходит до упора); «Мёртвая зона» — сколько хода в центре
    игнорируется (увеличьте, если взгляд сам ползёт); «Кривая» —
    больше 1 — малые отклонения медленнее, точнее.
  • «Фиксация оси» — вбок без вертикали / вверх-вниз без горизонтали.
  • «Инвертировать X / Y» — если обзор ходит наоборот.
  • «Клавиши на направления мини-стика» — вместо обзора мини-стик
    может жать клавиши: «Задать…» → клавиша, «Очистить», «Порог
    срабатывания». Пример (если обзор у вас головой): вверх/вниз —
    RCtrl+; / RCtrl+. (триммер тангажа, проверьте в DCS).
  • «Статус:» — работает ли.
Настройки этой подвкладки — свои в каждом профиле.

----------------------------------------------------------------------
2.2.5. ПОДВКЛАДКА «ЗУМ» (плавный зум ползунком X52)
----------------------------------------------------------------------
  • «Включить зум в этом профиле» — да во всех трёх.
  • «Зум работает в профилях колеса режимов» — отметьте все три
    (иначе в неотмеченном профиле зум «застынет» посередине).
  • «Ось X52» — подвигайте ползунок, выберите его ось.
  • «Инвертировать» — если зум наоборот.
  • «Фильтр дрожания» + «Порог, % хода» — 2 % (больше — сильнее гасит
    дрожь ползунка).
  • Строки «Ползунок X52» / «Зум в игре (после фильтра)» — проверка.
  В DCS: «Камера в кабине, общий вид - приблизить\отдалить» —
  в колонке X52 пусто, в колонке Controller (XBOX 360) — JOY_X.

----------------------------------------------------------------------
2.2.6. МЕНЮ «ПОСЛЕДОВАТЕЛЬНОСТИ» → «Просмотр последовательностей…»
----------------------------------------------------------------------
Библиотека макросов. Слева «Доступные последовательности»: «Новая»,
«Переименовать», «Удалить». Справа «Действия в последовательности»,
у каждого шага:
  • «Название:», «Модификатор:», «Клавиша:»;
  • «Задержка от начала, мс» — от НАЖАТИЯ КНОПКИ X52, а не от
    предыдущего шага;
  • «Длительность, мс» — сколько держать клавишу (обычно 100).
  «Добавить», «Сохранить изменения», «Удалить», «Закрыть».
  Одну последовательность можно назначить на разные кнопки и в разные
  профили; переименовали — ссылки обновятся.
  Пример «Запуск Су-27»: LCtrl+C / 0 / 100; RShift+Home / 2000 / 100.
  Пример «Серия ЛТЦ»: Insert / 0 / 80; Delete / 300 / 80; Insert / 600
  / 80; Delete / 900 / 80; Insert / 1200 / 80.

======================================================================
2.3. ВКЛАДКА «ОСИ И РУД»
======================================================================
Для Су-27 в DCS ручку и РУД DCS читает сам, поэтому здесь важно мало.
  • «Назначение осей» — какие оси X52 — крен, тангаж, рыскание, РУД,
    обзор: «Определить» → подвигать орган; «Инверсия»; «(авто)».
    Галочка слева у оси: снята — ось НЕ уходит в виртуальный геймпад,
    но её можно использовать как кнопку («Карта кнопок» → «Оси»).
    Для Су-27: крен/тангаж/рыскание/РУД — снимать не обязательно,
    если в DCS у колонки Controller удалены Крен/Тангаж/Тяга.
  • «Мёртвая зона мини-стика».
  • «Частота опроса, Гц» — 250 по умолчанию.
  • «Макс. обновлений в игру, в секунду» — 125 (меньше — легче для FPS).
  • «Фильтр дрожания осей» — 0.01.
  • «Калибровка РУД» — «Записать» 4 положения, «Сбросить калибровку»,
    «Проверка». Нужна для геймпада (ACE COMBAT); для Су-27 можно не
    делать.
  • «Применить в профилях» — галочки профилей, «Все», «Ни одного»,
    «Применить в отмеченных»: копирует настройки ЭТОЙ вкладки из
    текущего профиля. Для Су-27: «Все» → «Применить в отмеченных» —
    одинаково во всех трёх.

======================================================================
2.4. ВКЛАДКА «ОТКЛИК РУЧКИ»
======================================================================
Меняет, как ручка X52 передаётся в ВИРТУАЛЬНЫЙ ГЕЙМПАД (крен,
тангаж, рыскание кнопками). В DCS ручку читает сам DCS, поэтому для
Су-27 эта вкладка НЕ влияет на управление. Плавность ручки для Су-27
настраивается в DCS: «Настройка осей» → «Зона нечувствительности»,
«Кривизна». Для справки, что тут есть:
  • Крен / Тангаж: «Мёртвая зона X52», «Компенсация мёртвой зоны
    игры», «Чувствительность», «Кривая», «Сглаживание, мс»; график;
    «Плавно / Стандарт / Быстро»; «Крен → Тангаж (скопировать)».
  • «Рыскание (поворот рукояти)»: «Удержание» / «Импульсы», порог,
    отклонение, период, мин. импульс, задержка нажатия, сглаживание.
  • «Применить в профилях» — как на «Оси и РУД».

======================================================================
2.5. ВКЛАДКА «НАЗНАЧЕНИЕ (КАК В ИГРЕ)»
======================================================================
Тот же список, что на «Карте кнопок», но в виде таблицы действий и с
расширенными возможностями. Группа «Свои действия» — всё, что вы
назначили на «Карте кнопок».
  • «Назначить основную…» / «Назначить дополнительную…» — у действия
    ДВЕ кнопки X52 (например, шасси на тумблер T1 и на кнопку «C»).
    «Очистить основную / дополнительную».
  • «Порог оси…» — порог, если действие назначено на ось.
  • «Все по умолчанию» — сброс назначений.
  • «Своё действие (клавиша игры):» «Добавить…» / «Изменить…» /
    «Удалить» — окно своего действия:
      «Название», «Тип»: Удерживать · Переключатель · Автоповтор ·
        Последовательность · Смена профиля · Обзор DCS;
        («одно короткое нажатие» и «непрерывно > N мс» — только на
        «Карте кнопок»);
      «Срабатывание»: Нажатие · Отпускание · Короткое нажатие ·
        Долгое (≥ 500 мс);
      «Слой (колесо режимов)»: Все / 1 / 2 / 3 (если слои включены);
      «Клавиша в игре» → «Выбрать…» (галочка «Комбинация» — до 3 клавиш);
      «Повторять нажатие каждые, мс»;
      «Какой профиль включить» — для типа «Смена профиля»: в том числе
        «По кругу из списка» — «Добавить» / «Убрать» / ↑ ↓: Взлёт →
        Полёт → Посадка (именно в этом порядке, а не по всем профилям);
      «Шаги последовательности» — свои шаги прямо в действии,
        «Удержание», «По кругу», «Вернуться к 1-му шагу…», «При смене
        профиля начинать снова с 1-го шага».
  Чем отличается от «Карты кнопок»:
    • «Переключатель» — нажали — клавиша зажата, нажали ещё раз —
      отпущена. Нужен для клавиш, которые в игре надо ДЕРЖАТЬ, а кнопку
      держать неудобно. Пример: W «Тормоза колёс» на стоянке при
      гонке двигателей — нажали, тормоза держатся; нажали ещё — отпущены.
      Для щитка, шасси, фонаря Су-27 НЕ нужен: в DCS это и так
      клавиши-переключатели, им хватает одного нажатия.
    • «Смена профиля → По кругу из списка» — свой порядок профилей.
    • «Слой» — разные действия в разных положениях колеса.
  • «Выход в игру:» «Геймпад» / «Клавиатура / мышь» — «Клавиша…».
  • «Сейчас на X52:» — что нажато сейчас.
  Жёлтым подсвечиваются одинаковые привязки у разных действий.

======================================================================
2.6. ВКЛАДКА «РЕЖИМЫ И АВТОПРОФИЛЬ»
======================================================================
«Выбор профилей (общее для всех профилей)»
  • «Включить выбор профилей (галочки «в каких профилях»)» — показывает
    блоки «Применить и в профилях» в окне кнопки, на «Мини-стик»,
    «Зум», «Оси и РУД», «Отклик ручки». Для трёх профилей Су-27 —
    ВКЛЮЧИТЬ: общие кнопки настроите один раз.

«Слои по колесу режимов X52» (для этого профиля)
  • «Включить слои» — одна кнопка X52 = разные действия в положениях
    колеса 1 / 2 / 3. «Определить» у каждого положения / «Определить
    колесо автоматически…» (колесо в 1 → «Начать» → медленно в 2 и 3 →
    «Сохранить»).
  • ВНИМАНИЕ: колесо одно. Если колесо переключает ПРОФИЛИ (способ А),
    слои не включайте — колесо будет делать и то, и другое.
    Слои — это АЛЬТЕРНАТИВА трём профилям: один профиль «Су-27» со
    слоями 1 = взлёт, 2 = полёт, 3 = посадка. Разница: слои меняют
    только «Свои действия» кнопок; мини-стик, зум, оси — общие.
    Три профиля гибче, поэтому в этом примере — профили.

«Короткое и долгое нажатие»
  • «Долгое нажатие — дольше, мс:» 500 — порог для колонки «при долгом
    нажатии». Если долгие нажатия срабатывают случайно — 700.

«Оверлей в игре: название активного профиля»
  • «Показывать поверх игры»; «Всегда» или «При смене, секунд: 2»;
    «Место:» (сверху слева / по центру / справа и т.д.), «Размер:», «Цвет…», «Непрозрачность:»;
    «Показывать и слой колеса»; «Показать для проверки».

«Профиль по колесу режимов X52 (общее для всех профилей)»
  • «Поворот колеса включает профиль:» + профиль для положений 1/2/3
    (или «— не переключать —»), «Определить», «Определить колесо
    автоматически…». Для Су-27 — способ А из части 1.
  • «Открывать «Свойства» X52 (joy.cpl) при запуске» — включить, ТОЛЬКО
    если колесо не видно в «Сейчас нажаты кнопки X52» (особенность
    некоторых драйверов).

«Автопереключение профиля»
  • «Автоматически включать профиль нужной игры / самолёта».
  • «Программы игры (exe, через запятую):» — DCS.exe; «+ последняя
    игра» — подставит exe игры, из которой вы только что вышли Alt+Tab.
  • «+ текущий самолёт» — сядьте в кабину Су-27, нажмите: в профиль
    добавится «Su-27». Добавьте его ТОЛЬКО в «Взлёт Су-27»: сели в
    Су-27 — включился взлёт; дальше колесом. Выбранный вручную/колесом
    профиль автопрофиль не перебивает, пока вы в той же игре.
  • «DCS World: скрипт определения самолёта» — «Установить в DCS»
    (одна строка в Export.lua, SRS/Tacview не мешает), «Удалить из
    DCS», «Открыть папку Scripts». Без скрипта лаунчер знает только
    «DCS запущен», но не какой самолёт.

2.7. ВКЛАДКА «ОБЗОР (ГОЛОВА / X52)»

    opentrack вместе с галочкой»; «opentrack.exe:» → «Обзор…»;

Хатка обзора X52 всегда главнее головы — быстро оглянуться можно и с
трекером.
